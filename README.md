# Sistem-Informasi-Inventaris-Monitoring-Kegiatan-Desa-Wonomulyo
Melaksanakan proyek mini berdampak berupa perancangan dan pengembangan sistem informasi manajemen sarana dan prasarana berbasis web untuk Balai Desa Wonomulyo. Kegiatan diawali dengan observasi dan identifikasi kebutuhan mitra terkait pengelolaan data inventaris serta kegiatan yang masih memerlukan pencatatan dan pemantauan secara terstruktur. Berdasarkan hasil identifikasi tersebut, mahasiswa merancang basis data dan antarmuka aplikasi, mengembangkan sistem, serta melakukan uji coba untuk memastikan sistem dapat digunakan sesuai kebutuhan mitra. Produk yang dihasilkan berupa Sistem Informasi Manajemen Sarana dan Prasarana Balai Desa Wonomulyo, yaitu aplikasi berbasis web yang digunakan untuk membantu pengelolaan data inventaris dan kegiatan secara terintegrasi. Sistem dilengkapi dengan beberapa fitur, yaitu halaman login, beranda/dashboard, pendataan inventaris, kegiatan dan kalender, reminder, monitoring kegiatan, laporan, pengelolaan pengguna, serta pengaturan sistem. Fitur inventaris digunakan untuk membantu pencatatan dan pengelolaan aset, sedangkan fitur kegiatan, kalender, reminder, dan monitoring digunakan untuk membantu mitra dalam mengatur serta memantau kegiatan. Sistem juga menyediakan fitur laporan untuk membantu penyusunan dan dokumentasi data secara lebih terstruktur.
